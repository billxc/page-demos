macOS Spellcheck: Missing or Wrong-Language Suggestions

A Chromium bug can cause Chrome and WebView2 on macOS to underline a misspelled word correctly but show suggestions in a different language, or no suggestions at all. The mismatch occurs when automatic spellchecking detects a language different from the one used to generate suggestions.

Actual Behavior in Affected Versions

Input: “Bonjour, je vais parler francais avec mes amis.”

The word is underlined based on French spelling, but right-clicking may suggest Francis, Francois instead of the French correction.

Safari / TextEdit in the Same Scenario

Input: “Bonjour, je vais parler francais avec mes amis.”

Safari and TextEdit offer the French correction français, matching the language used for the spelling check.

1. When the Bug Occurs

A typical reproduction scenario is:

  • The Mac uses English as its primary display language.
  • System Settings → Keyboard → Text Input → Edit → Spelling is set to “Automatic by language”.
  • The user enters a French sentence in a spellcheck-enabled editable field in Chrome or WebView2.

The issue is not limited to French: the underlying problem is a mismatch between the automatically detected text language and the fallback language used for suggestions.

2. What Users See

Spelling detection and correction suggestions become inconsistent. A red underline can appear correctly, but the context menu does not offer a useful correction in the language being typed.

Symptom Sample Sentence Actual vs. Expected
Wrong-language suggestions Bonjour, je vais parler francais avec mes amis demain. May suggest Francis, Francois instead of the French correction français.
No suggestions Nous devons developper une nouvelle methode rapidement. methode is underlined, but no suggestions are shown. The expected French correction is méthode.

Exact suggestions can vary with the macOS version and spelling configuration.

3. How to Reproduce

  1. Use an English Mac with Spelling set to “Automatic by language”.
  2. Open this page in an affected Chrome or macOS WebView2 runtime with spellchecking enabled.
  3. Choose a sample below, or type the sentence into the editable field with a trailing space.
  4. Wait for the red underline, then right-click francais or methode and compare the suggestions with the expected French correction.
The examples above use styled underlines for illustration. This editable field uses the browser’s native spellchecker.
